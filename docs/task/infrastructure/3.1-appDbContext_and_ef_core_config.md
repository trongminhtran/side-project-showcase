## Design Constraints
- Use EF Core Fluent API ONLY
- Domain entities must remain persistence-ignorant
- No data annotations in Domain
- No business logic in Infrastructure

## Required Behavior

### AppDbContext
- DbSets:
  - Projects
  - Reactions
  - Ratings
  - Comments
- Apply configurations via ApplyConfigurationsFromAssembly

### Project Mapping
- Key: Id
- Required: OwnerId, Title, Visibility, CreatedAt
- Max length:
  - Title: 200
- Index:
  - OwnerId

### Reaction Mapping
- Key: Id
- Required: ProjectId, UserId, Type, CreatedAt
- Unique index:
  - (ProjectId, UserId)

### Rating Mapping
- Key: Id
- Required: ProjectId, UserId, Score, CreatedAt
- Unique index:
  - (ProjectId, UserId)

### Comment Mapping
- Key: Id
- Required: ProjectId, UserId, Content, CreatedAt
- Optional:
  - ParentCommentId
- Index:
  - ProjectId
  - ParentCommentId

## Forbidden
- EF attributes in Domain
- Cascade business logic
- Navigation properties required for aggregates

## Output
Clean EF Core infrastructure code
