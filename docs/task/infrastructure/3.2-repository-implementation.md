## Task Name
Implement EF Core Repositories

## Layer
Infrastructure

## Related Specs
- domain-rules.md
- api-contract.md

## Files to Create
- Repositories/ProjectRepository.cs
- Repositories/ReactionRepository.cs
- Repositories/RatingRepository.cs
- Repositories/CommentRepository.cs

## Design Constraints
- Repositories implement Application interfaces ONLY
- No business logic
- No validation logic
- Use EF Core DbContext

## Required Behavior

### ProjectRepository
Implements IProjectRepository:
- Add(Project project)
- GetById(Guid projectId)

### ReactionRepository
Implements IReactionRepository:
- GetByProjectAndUser(Guid projectId, Guid userId)
- Add(Reaction reaction)
- Remove(Reaction reaction)
- CountByProject(Guid projectId)

### RatingRepository
Implements IRatingRepository:
- GetByProjectAndUser(Guid projectId, Guid userId)
- Add(Rating rating)
- Remove(Rating rating)
- GetAverageScore(Guid projectId)

### CommentRepository
Implements ICommentRepository:
- GetById(Guid commentId)
- Add(Comment comment)

## Forbidden
- Business rules
- Domain logic
- EF tracking hacks
- Lazy loading

## Output
Clean EF Core repository implementations
