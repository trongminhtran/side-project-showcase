## Design Constraints
- Controllers must be thin
- No business logic
- Map Request DTO → Command
- Return proper HTTP status codes
- Use dependency injection

## Required Behavior

### ProjectsController
POST /api/v1/projects
- CreateProjectCommand
- Return 201 Created
- Return projectId

### ReactionsController
POST /api/v1/projects/{projectId}/reactions
- ReactProjectCommand
- Return 200 OK
- Return likeCount, loveCount

### RatingsController
POST /api/v1/projects/{projectId}/ratings
- RateProjectCommand
- Return 200 OK
- Return average, userScore

### CommentsController
POST /api/v1/projects/{projectId}/comments
- CommentProjectCommand
- Return 201 Created
- Return commentId

## Forbidden
- Validation logic duplicated from Domain
- Direct DbContext usage
- Business logic in controller

## Output
Clean ASP.NET Core controllers
