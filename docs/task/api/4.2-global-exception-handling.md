## Task Name
Implement GlobalExceptionMiddleware

## Layer
API

## Requirements
- Catch all unhandled exceptions
- Map:
  - DomainException -> 400
  - KeyNotFoundException -> 404
  - UnauthorizedAccessException -> 401
  - InvalidOperationException -> 400
  - Default -> 500
- Return JSON:
  {
    "error": "message"
  }
- Do NOT expose stack trace
