## Design Constraints
- Reaction is immutable after creation
- No update, toggle, or change methods
- One reaction per user per project is enforced at application layer

## Required Behavior
- Reaction has:
  - Id (Guid)
  - ProjectId (Guid)
  - UserId (Guid)
  - Type (ReactionType)
  - CreatedAt (DateTimeOffset)

- Constructor must:
  - Reject empty ProjectId
  - Reject empty UserId

## Forbidden
- Any Update / Change / Toggle methods
- Any framework or EF Core references
