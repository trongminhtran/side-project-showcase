## Task Name
Implement Comment Aggregate

## Layer
Domain

## Related Specs
- domain-rules.md
- comment-spec.md

## Files to Create
- Comments/Comment.cs

## Design Constraints
- Comment is immutable after creation
- Only one level of reply is allowed
- No edit, delete, or moderation methods

## Required Behavior
- Comment has:
  - Id (Guid)
  - ProjectId (Guid)
  - UserId (Guid)
  - Content (string)
  - ParentCommentId (Guid?)
  - CreatedAt (DateTimeOffset)

- Constructor must:
  - Reject empty ProjectId
  - Reject empty UserId
  - Reject empty or whitespace Content

- Thread rule:
  - ParentCommentId may be null (top-level)
  - Domain does NOT validate parent existence
  - Domain does NOT allow deeper nesting logic

## Forbidden
- Any Update/Edit/Delete methods
- Any recursion or tree logic
- Any framework or EF Core references

## Output
Clean, immutable C# domain code
