## Task Name
Implement Rating Aggregate

## Layer
Domain

## Related Specs
- domain-rules.md
- rating-spec.md

## Files to Create
- Ratings/Rating.cs

## Design Constraints
- Rating is immutable after creation
- No update or change methods
- Score validation is enforced in domain

## Required Behavior
- Rating has:
  - Id (Guid)
  - ProjectId (Guid)
  - UserId (Guid)
  - Score (int)
  - CreatedAt (DateTimeOffset)

- Constructor must:
  - Reject empty ProjectId
  - Reject empty UserId
  - Reject Score < 1 or > 5

## Forbidden
- Any UpdateScore / ChangeScore methods
- Any framework or EF Core references
- Creating update/edit/mutate methods
- Anticipating future features

## Output
Clean, immutable C# domain code
