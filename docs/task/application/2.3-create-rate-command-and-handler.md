## Design Constraints
- Application enforces:
  - Project existence
  - Project visibility (must be Public)
  - One rating per user per project
- Domain Rating is immutable

## Required Behavior
### RateProjectCommand
- Properties:
  - ProjectId (Guid)
  - UserId (Guid)
  - Score (int)

### Handler Responsibilities
1. Load project by ProjectId
2. Reject if project not found
3. Reject if project is Private
4. Check existing rating by (ProjectId, UserId)
5. If exists → remove old rating
6. Create new Rating aggregate
7. Persist rating
8. Calculate:
   - Average rating
   - Current user rating
9. Return result DTO

## Repository Contracts
### IProjectRepository
- GetById(Guid projectId)

### IRatingRepository
- GetByProjectAndUser(Guid projectId, Guid userId)
- Add(Rating rating)
- Remove(Rating rating)
- GetAverageScore(Guid projectId)
